## 1. Overview
This updated design system merges the authentic KBCC college layout (top strip, official header logo, maritime hero banner with wave graphics, sidebar navigation, and 3-column footer) with our interactive "bubble-like" club directory.

It requires **no build tools or bundlers**—simply link `style.css` and `preview.js` in your output HTML.

## 2. Card HTML Template for Python (`build_page.py`)

When your Python script loops over the scraped CSV rows (`scrape.py`), generate each club bubble card with this exact markup:

```python
def render_club_card(club_name, category, category_slug, description, meeting_info, signup_type, signup_url):
    """
    signup_type: 'link' | 'email' | 'pending'
    category_slug: 'academic' | 'arts' | 'social' | 'sports'
    """
    if signup_type == "link":
        action_btn = f'''<a href="{signup_url}" target="_blank" rel="noopener noreferrer" class="btn-card btn-join">
            <span>Join now</span>
            <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
              <line x1="5" y1="12" x2="19" y2="12"></line>
              <polyline points="12 5 19 12 12 19"></polyline>
            </svg>
          </a>'''
    elif signup_type == "email":
        action_btn = f'''<a href="mailto:{signup_url}?subject=Interested%20in%20joining%20{club_name}" class="btn-card btn-email">
            <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
              <path d="M4 4h16c1.1 0 2 .9 2 2v12c0 1.1-.9 2-2 2H4c-1.1 0-2-.9-2-2V6c0-1.1.9-2 2-2z"></path>
              <polyline points="22,6 12,13 2,6"></polyline>
            </svg>
            <span>Email to join</span>
          </a>'''
    else:  # pending confirmation
        action_btn = '''<button type="button" class="btn-card btn-pending" disabled>
            <span>Signup pending confirmation</span>
          </button>'''

    return f'''
    <article class="club-card" data-category="{category_slug}">
      <div class="card-top">
        <span class="card-category-badge {category_slug}">{category}</span>
        <h3 class="club-name">{club_name}</h3>
        <p class="club-description">{description}</p>
      </div>
      <div class="card-bottom">
        <div class="club-meta">
          <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
            <circle cx="12" cy="12" r="10"/><polyline points="12 6 12 12 16 14"/>
          </svg>
          <span>{meeting_info}</span>
        </div>
        <div class="card-action">
          {action_btn}
        </div>
      </div>
    </article>
    '''
```

## 5. Maritime Midnight Dark Mode System

The directory includes a **Maritime Midnight Dark Mode** toggle (`🌙 Dark` / `☀️ Light`) integrated into the top utility strip.

> **Crucial Note for the Page Builder Team (`build_page.py`):**  
> `build_page.py` requires **NO code changes** to support dark mode. The HTML card markup generated by Python remains 100% identical because all color adaptation, card surface elevation, and contrast adjustments are handled automatically by CSS custom properties under `[data-theme="dark"]`.

### Dark Mode Design Tokens (`[data-theme="dark"]` in `style.css`)

| Variable | Dark Mode Hex | Visual Role |
| :--- | :--- | :--- |
| `--foam` | `#0B1926` | Deep Midnight background |
| `--surface-card` | `#132639` | Elevated card surfaces |
| `--surface-subtle` | `#18324B` | Inputs / chip backgrounds |
| `--border-card` | `#1F3E5C` | Card borders |
| `--mist` | `#1E3A57` | Subtle dividers |
| `--ink` | `#E2EDF5` | High-contrast ice-white text |
| `--muted` | `#8BA9C4` | Secondary text |
| `--harbor` | `#091A2B` | Header strip, hero, and footer background |

### How Dark Mode Operates
- **Zero-Flash (Anti-FOUC):** An inline `<script>` in the `<head>` checks `localStorage.getItem('kbcc-theme')` and OS `prefers-color-scheme: dark` before CSS paint, eliminating white flashes during reload.
- **Persistent Preferences:** The user's active theme is stored in browser `localStorage` under `kbcc-theme`.
- **System Preference Detection:** Automatically syncs with the user's OS dark mode setting on first visit and adapts on system theme changes when no manual preference is pinned.

## 6. Summary of Merged Layout
- **Page Container:** `width: min(1160px, 100% - 2.5rem); margin-inline: auto;`
- **Main Layout Grid:** 2-column layout (`260px` sticky sidebar + `1fr` main clubs area).
