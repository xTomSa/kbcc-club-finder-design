## 📌 Project Overview
This repository contains the design system, HTML markup template, and CSS styling for the Kingsborough Community College (KBCC) **Student Club Directory**.

The goal of the site is to give students a clean, responsive, and searchable directory of active student clubs where they can immediately find how to join ("Join now" link, "Email to join", or "Pending confirmation").

---

## 🎨 Design Deliverables
- **`style.css`**: Pure modern CSS using custom properties (`:root`), styled with official KBCC brand colors (Ocean Teal `#0e525a` and Warm Gold `#e59a38`).
- **`index.html`**: Semantic prototype page displaying the hero header, search input, category filters, and sample club cards.
- **`preview.js`**: Lightweight search and filter prototype for live testing.
- **`HANDOFF.md`**: Direct integration guide and Python f-string snippet for the **Page Builder Team** (`build_page.py`).

## 📋 Color Tokens Reference

| Variable | Hex Value | Role |
| :--- | :--- | :--- |
| `--kbcc-teal` | `#0e525a` | Primary Header, Navigation, Outline Buttons |
| `--kbcc-gold` | `#e59a38` | Accent Highlights, "Join now" Primary CTA |

| `--surface-card` | `#ffffff` | Club Card Surface |
